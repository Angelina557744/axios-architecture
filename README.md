## 📖 О проекте

**AXIOS** — сайт архитектурного бюро из Санкт-Петербурга. Вымышленная компания, созданная для демонстрации навыков фронтенд-разработки: 3D-графика, анимации, типографика, работа с формами.

Сайт задуман как **реальный коммерческий заказ**: премиум-бюро, которое продаёт дорогие услуги через визуал. Задача — сделать так, чтобы заказчик увидел сайт и захотел такой же для своей компании.

### Легенда компании

- **Название:** AXIOS (греч. «достойный, ценный», читается как «ось» — axis)
- **Слоган:** «Форма, рождённая смыслом»
- **Основано:** 2012, Санкт-Петербург
- **Профиль:** жилые комплексы, частные резиденции, общественные пространства, реставрация
- **География:** Россия, Европа, ОАЭ
- **Цифры:** 87 проектов, 14 лет, 9 наград, 3 страны

### Ключевые фичи

- **3D-сцена в hero** — параметрическая форма на Three.js, реагирует на мышь и скролл
- **Кастомный курсор** — точка + кольцо с lerp-анимацией
- **Прелоадер** — логотип вычерчивается SVG-линиями, счётчик загрузки
- **Плавный скролл** — Lenis + ScrollTrigger
- **Анимация текста** — SplitType (по буквам и строкам)
- **Скролл-триггеры** — появление секций, счётчики, таймлайн, прогресс-бар
- **Шум (grain)** — тонкий слой поверх всего сайта
- **Кастомный hover** — карточки, кнопки, ссылки
- **Форма обратной связи** — валидация на клиенте, отправка через Web3Forms
- **Фильтры** — на странице проектов и команды
- **FAQ-аккордеон** — плавное раскрытие
- **Доступность** — `aria-label`, `alt`, `prefers-reduced-motion`, семантика
- **Адаптив** — мобилка, планшет, десктоп

## 🛠 Стек

Проект — **чистая статика**, без сборщиков и фреймворков. Всё работает через CDN.

| Слой | Технология | Зачем |
|---|---|---|
| Разметка | HTML5 | Семантика, SEO |
| Стили | Tailwind CSS (CDN) | Быстрая вёрстка |
| Кастомные стили | CSS3 | Переменные, grid, анимации |
| Логика | Vanilla JS | Без фреймворков |
| Анимации | GSAP 3.12 + ScrollTrigger | Скролл-триггеры, timeline |
| 3D | Three.js r160 | Hero-сцена |
| Плавный скролл | Lenis 1.1 | Инерция |
| Текст | SplitType 0.3 | Разбивка на буквы |
| Иконки | Lucide | Векторные иконки |
| Шрифты | Google Fonts | Space Grotesk, Inter, JetBrains Mono |

**Никаких зависимостей, никакой сборки.** Открываешь `index.html` — сайт работает.

## 🎨 Дизайн-система

### Цвета

| Роль | HEX | Применение |
|---|---|---|
| Фон основной | `#0A0A0B` | Основной фон |
| Фон вторичный | `#121214` | Секции, карточки |
| Фон третичный | `#1A1A1E` | Hover, границы |
| Акцент | `#C6FF3D` | Кнопки, ссылки, hover, цифры |
| Акцент вторичный | `#E8E2D5` | Подзаголовки |
| Текст основной | `#F5F5F0` | Body, заголовки |
| Текст вторичный | `#8A8A8F` | Мета, подписи |

### Типографика

- **Заголовки:** Space Grotesk (500, 700)
- **Body:** Inter (400, 500)
- **Мета/цифры:** JetBrains Mono (400, 500)

### Принципы

- Тёмный фон + лаймовый акцент — современный премиум.
- Абстракция оправдана смыслом: линии, сетки, координаты, «чертёжный» вайб.
- Дозированный акцент: лайм — это «лазер», а не заливка.
- Моноширинный шрифт для мета-информации — «инженерный» характер.
